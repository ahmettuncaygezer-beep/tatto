# Tuncay Gezer Atelier

Luxury Dark Avant-Garde Tattoo Art Website built with Next.js 15, React 19, TypeScript, and Tailwind CSS.

## 🚀 Başlangıç (Getting Started)

### Gereksinimler
- Node.js (v18.17+ veya v20+)
- npm veya pnpm / yarn

### Kurulum

1. Bağımlılıkları yükleyin:
```bash
npm install
```

2. (İsteğe bağlı) Ortam değişkenlerini ayarlayın:
`.env.example` dosyasını `.env.local` olarak kopyalayabilir ve Telegram bot ayarlarınızı yapabilirsiniz:
```bash
cp .env.example .env.local
```
*(Belirtilmezse form başvuruları geliştirme konsoluna yazdırılır.)*

3. Geliştirme sunucusunu başlatın:
```bash
npm run dev
```

Tarayıcınızda [http://localhost:3000](http://localhost:3000) adresini açın.

### Üretim Derlemesi (Build)

```bash
npm run build
npm run start
```
